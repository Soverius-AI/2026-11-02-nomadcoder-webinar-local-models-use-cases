# Workshop development

Build only the examples requested by the user. Keep the documented workshop sequence in README.md.

Reuse existing demonstrations selectively and preserve their original repositories. Do not copy credentials, model weights, local databases or unrelated application history.

Keep runnable instructions beside each example. Distinguish scaffolded, implemented and verified behavior. Explicitly document hosted calls when an example uses them.

Do not manufacture benchmark results or treat incomplete runs as completed. The existing benchmark repository owns its methodology and results; this repository contains the workshop walkthrough and links unless the user requests otherwise.

We have an LLM Wiki. Consider whether durable technical findings or teaching decisions warrant an update. Presentation logistics and scaffolding alone do not require ingestion.
